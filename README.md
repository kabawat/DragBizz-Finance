# DragBizz Finance

Handles payment orders, verification and webhooks. Core owns package prices and subscriptions.

Supports Razorpay, Stripe, Cashfree, PayU and Easebuzz; uses MongoDB and central Redis (`finance_user`).

Built with Node.js. Application code is in `src/`; configuration is in `env.example`.

See [SETUP.MD](SETUP.MD) for setup and run commands.
